Cookie & Tracking Notice

Version 1.0 · Last updated 19 September 2026

1. This website

This website sets no cookies and runs no analytics or advertising scripts. It is a set of static files. The only network requests it makes are for its own assets, its fonts (served from this domain, not a third party) and the release metadata file it reads to show the current download.

Without cookies or client-side storage, we cannot and do not recognise returning visitors, and there is no consent banner to dismiss because there is nothing to consent to.

2. The app

The app stores data on your device to function — your profile answers, targets, meal log, water and weight entries, and the offline food catalogue. That storage is local to the app and is not a tracking mechanism.

The app contains no third-party analytics or advertising SDKs. It sends data only for the purposes described in the Privacy Policy: meal analysis you request, catalogue updates, and a version check.

3. Hosting

Our hosting and file-delivery providers may keep standard server logs (IP address, user agent, requested file, timestamp) for security and abuse prevention. These are infrastructure logs, not user profiles. [hosting provider and log retention — to be supplied]

4. If this changes

If analytics or cookies are ever introduced, this page will name them, state their purpose and lifetime, and a consent mechanism will be added where the law requires one. We will not add tracking silently.
